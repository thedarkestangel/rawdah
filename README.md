# Rawdah – vers, hage og hifz

## Legg den ut (GitHub Pages)
1. Lag et repo på GitHub, f.eks. `rawdah` (Public).
2. Add file → Upload files: last opp alle filene i denne mappen.
3. Settings → Pages → Deploy from a branch → main / root → Save.
4. Etter ca. 1 minutt: `https://<brukernavn>.github.io/rawdah/`

## iPhone
Safari → Del → Legg til på Hjem-skjerm. Tilfeldige avbrudd: se Meg-fanen i appen (Snarveier).

## Android (Pixel)
Chrome → åpne adressen → «Installer app» (eller ⋮ → Legg til på startskjermen).
Tilfeldige avbrudd: MacroDroid, se Meg-fanen i appen.
